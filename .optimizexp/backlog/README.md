# OptimizeXP experiment backlog

Global ranked uplift experiments from persona surveys and positive-metric gaps.

- **Schema / policy:** `.agents/skills/optimizexp/references/experiment-backlog.md`
- **Canonical file:** `experiments.json` (created/updated by `harness/survey.mts --mode rank-backlog --global`)
- Per-run copies: `.optimizexp/runs/<run-id>/backlog.json`

Do not put secrets here. Treat as product feedback data for agents.
