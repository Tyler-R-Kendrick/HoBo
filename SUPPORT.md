# Support

HoBo is currently a design and executable-proof repository, not a production service.

## Where to start

- Project overview: [`README.md`](./README.md)
- Design suite: [`docs/design/README.md`](./docs/design/README.md)
- Contribution workflow: [`CONTRIBUTING.md`](./CONTRIBUTING.md)
- Security reporting: [`SECURITY.md`](./SECURITY.md)
- Agent setup: [`docs/agent-tooling.md`](./docs/agent-tooling.md)

## Getting help

Use GitHub issues or discussions if enabled by the repository maintainers. Include:

- What you were trying to understand or change.
- Relevant files, issue IDs, or design plan anchors.
- Commands run and their output.
- Whether you are using an AI agent and which one.

For security-sensitive issues, follow [`SECURITY.md`](./SECURITY.md) instead of opening a public issue.
