# Data model contracts

This directory is generated by `node --import tsx scripts/generate-data-model-contracts.ts`. It is the repository-wide bridge that makes every HoBo-authored TypeScript data-model module visible to Protobuf and CUE.

- `data-models.proto` declares one protobuf message per tracked data-model source module and annotates each message with its source path plus CUE definition.
- `data-models.cue` constrains every protobuf-backed data model with source-path, package, domain, integration-boundary, and `cueAnnotated: true` invariants.
- `pnpm run contracts:data-models` verifies the generated Protobuf/CUE catalog stays in sync with tracked TypeScript data-model modules.

Current generated coverage: 423 TypeScript data-model modules.
