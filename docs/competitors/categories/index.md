# Competitor categories

> Thirteen closed categories. Membership is many-to-many and is declared in each canonical capture's `competitor.categories` front matter — never on this page. See [`../metadata-contract.md`](../metadata-contract.md).

| Category | Scope | Competitors |
| -------- | ----- | ----------- |
| [Comprehensive Platform Orchestrators](platform-orchestrators.md) | Systems that own application and platform orchestration end to end: environment management, resource abstraction, governance, and developer self-service in one control plane | 5 |
| [Portable Application Models & Control Planes](portable-application-models.md) | Application-intent models, programmable resource/capability abstractions, composition engines, placement, reconciliation, and portable control-plane APIs | 8 |
| [Cloud Application Platforms](cloud-application-platforms.md) | Managed platforms that own application and environment lifecycle, services, previews, deployment, runtime operations, or BYOC realization | 14 |
| [Developer Portals & IDPs](developer-portals-idps.md) | Developer-facing catalogs, scaffolding, self-service workflows, scorecards, and platform interfaces that can front or partially substitute HoBo | 1 |
| [Infrastructure-from-Code & Authoring](infrastructure-from-code.md) | Developer authoring frameworks that infer or provision infrastructure from application code, typed resources, bindings, permissions, and deployment intent | 8 |
| [Runtime & Distributed Application Substrates](runtime-substrates.md) | Runtimes, schedulers, component hosts, actor systems, service building blocks, and fleet substrates | 10 |
| [Hybrid & Multicloud Enterprise Orchestration](hybrid-multicloud-enterprise.md) | Enterprise hybrid/multicloud provisioning, governance, catalog, lifecycle, and application-orchestration systems with broad control-plane overlap | 1 |
| [Self-Hosted PaaS & Server Deployment](self-hosted-paas.md) | Simple self-hosted PaaS and server/container deployment systems | 3 |
| [Agentic Infrastructure & Operations](agentic-infrastructure.md) | AI-native infrastructure modeling, autonomous remediation, agent tool surfaces, operational world models, and agent-governed platform control | 4 |
| [Backend & Data Application Platforms](backend-data-platforms.md) | Integrated BaaS/data platforms collapsing provisioning, functions, auth, storage, realtime bindings, and application runtime | 5 |
| [Delivery, Release & GitOps](delivery-release-gitops.md) | Delivery controllers, release orchestration, GitOps reconciliation, environment promotion, rollout strategies, runbooks, and deployment lifecycle systems | 1 |
| [FinOps, Governance & Placement](finops-governance-placement.md) | Cost visibility, allocation, estimation, optimization, policy, governance, and placement systems | 2 |
| [Identity, Networking & Application Delivery](identity-networking-delivery.md) | Identity-aware networking, secretless connectivity, ADC/gateway, mesh, exposure, and auth-broker systems | 3 |

Every competitor also appears in the [cross-category matrix](../matrix.md), which is generated from the same front matter.
