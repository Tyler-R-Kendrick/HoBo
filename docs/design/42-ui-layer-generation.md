# Plan 42 — UI-layer generation — REMOVED (out of scope)

> **Removed in the AI-native meta-cloud refocus** ([ADR-0064](./adr/ADR-0064-scope-ai-native-meta-cloud.md)). Generating the developer's own application **UI** is **app-build-out**, not meta-cloud infrastructure. HoBo's AI generation is scoped to **infrastructure + runtime** — the **Forge** (providers/adapters/implementations, [Plan 33](./33-forge-generation-pipeline.md)) and self-optimizing runtime functions (`"use training"`, [Plan 23](./23-stubbable-ai-implementations.md)). For HoBo's own control-plane UI see [Plan 7](./07-ui-dashboard.md).
>
> The plan number is retained as a tombstone so existing links resolve; ADR-0056 (UI-generation + design-system) is withdrawn.
