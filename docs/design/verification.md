# Verification, Testing & Open Questions

This capability doc consolidates Plan 9 of the HoBo design suite.

## Plan 09

**Plan 9 — Verification, testing & open questions**

> **Resource Definitions & Matching (Humanitec parity):** add **Driver** conformance suites ([Plan 25](./platform-engineering.md#plan-25)) and a **matching test** (given context + a set of Resource Definitions, assert the expected one wins and a `match.Decided` event records the score, [Plan 25](./platform-engineering.md#plan-25)) and a **Delta→Set** test (a delta applied yields the expected immutable Set, [Plan 25](./platform-engineering.md#plan-25)). The matching test also asserts **determinism** (same inputs → same winner on replay), the **stable tiebreak + `PlanWarning`** on a true tie, and a **`require`-miss → `deployment.PlanRejected`** ([ADR-0033](./adr/05-config-matching-environments.md#adr-0033)).

> **Contracts & policy (gates):** **conformance** here is the *provider* contract (does an impl satisfy a port); the *consumer-driven* compatibility check (`can-deploy`, [Plan 29](./contracts-policy-flags.md#plan-29)) is distinct — add a **compatibility test** (producer/consumer version skew → `compat.GateFailed`), a **policy-decision test** ([Plan 29](./contracts-policy-flags.md#plan-29): assert effect + obligations for a given request), and an **eval-gate test** ([Plan 23](./forge-generated-stack.md#plan-23)). `hobo verify` composes all of these.

> **Runtime/IfC integration.** Conformance is now **per WIT interface** ([Plan 20](./wasm-runtime-wit.md#plan-20)) and is the gate for both human- and Forge-generated **providers and implementations** ([Plan 23](./forge-generated-stack.md#plan-23)). Add: a **stub/replay test** (run with stubs, then assert an AI-generated impl reproduces recorded traces + passes conformance) and an **IfC-collection test** (collected manifest matches a fixture). New open questions: wasm host of record, `hobo:*` WIT versioning, IfC fidelity for non-TS languages, and the "low-risk auto live-fix" threshold.

### Testing strategy (the pyramid)
1. **Unit** — pure functions (the Planner, upcasters, capability negotiation) tested in isolation. The Planner being pure ([Plan 4](./control-plane.md#plan-04)) makes provider-resolution fully unit-testable without a cloud.
2. **Conformance (contract) tests** — `@hobo/conformance` is the centerpiece (below).
3. **Integration** — SDK + built-in runtime + a real-but-local provider (containers) exercise deploy→run→inspect.
4. **E2E** — full Yard + one real cloud provider, gated and periodic (cost-aware).
5. **Determinism/replay** — every durable run asserts `replay == live state`.

### `@hobo/conformance` — the trust boundary
A shared, executable contract test suite per **port** (runtime ports and Provider capability ports). It is what lets human- *and* Forge-generated adapters be trusted ([Plan 6](./ai-native-agent-auth.md#plan-06)).
- **Per runtime port:** EventStore (append/read/optimistic-concurrency/idempotent-dedup), Queue (at-least-once + dedup), Streamer, ActorHost (lease + fencing under contention), Clock (durable timers, deterministic replay), **`component-host`** (deterministic-clock trace replay, `wasi:*` round-trip, link semantics, capability-handle isolation — the host-portability gate, [ADR-0031](./adr/01-architecture-core.md#adr-0031)).
- **Per Provider capability:** e.g. `database` must provision, accept connections via the agnostic client, honor `require`/`prefer`, `refresh()` report drift, and `destroy()` cleanly — same assertions whether AWS, Azure, or a Forge-generated provider.
- **Per SDK idiom layer (`@hobo/conformance/sdk`, [ADR-0072](./adr/01-architecture-core.md#adr-0072)):** a per-language idiom layer over the `hobo:sdk` world must add **no semantics** — identical inputs **lower to identical WIT calls + identical manifest IR** as the reference (golden-IR equivalence + replay). This is what makes "the SDK is provided through WIT" true rather than aspirational; it gates hand-authored **and** SWE-operator-generated ([Plan 40](./operators-sre.md#plan-40)) idiom layers alike.
- **Gate:** an adapter may only claim a port/capability it passes; CI blocks publishing otherwise; the Forge runs this suite sandboxed before certifying.
- **`local` vs `camp` tag (local-dev fidelity, [ADR-0042](./adr/07-portability-extensibility.md#adr-0042)):** every conformance check is tagged `local` (passes offline on `runtime-local` — simulate/real behaviors) or `camp` (passes only against a real provider — IAM/mTLS/quotas/drift). `hobo dev` runs `local`; a Camp run runs `camp`; **`hobo verify` reports coverage = `local ∪ camp` and refuses a prod-ready claim while `camp` checks are unrun** — so a green local run is honest about what it didn't test.

### Boundary virtualization & the test sandbox — low-friction testing ([ADR-0076](./adr/04-governance-verification.md#adr-0076))
The biggest DX lever is making it cheap to test a service *without* standing up the whole system or hand-writing mocks. Because every boundary is a **link** with a **PACT contract** ([Plan 29](./contracts-policy-flags.md#plan-29)/[Plan 20](./wasm-runtime-wit.md#plan-20)), the host can serve any boundary in a **mode** (the [stub](./forge-generated-stack.md#plan-23) mechanism, generalized): `live` · `mock` (contract-conformant fake auto-served from the contract + recorded traces) · `record`/`replay` · `fork` · `shadow` · `fault`. No new subsystem — `mock`/`record`/`replay` are stubs, `shadow` is the eval/champion-challenger path, `fault` is `chaos` ([ADR-0047](./adr/04-governance-verification.md#adr-0047)) scoped to a boundary.

Two ways to isolate a system-under-test, **request-level first**:
- **`hobo sandbox` / `hobo test` — auto-mocked SUT.** Run the service(s) under test with **every out-of-scope boundary auto-`mock`ed from its contract** (zero hand-written mocks; the mock exercises the real expected shape, and a contract change fails the test by construction). Pure-local, offline, deterministic.
- **`hobo dev --fork <service>` — request-level isolation (bridge-to-Kubernetes style).** Your local/branch build of one service **joins a shared baseline environment in your lane**; requests carrying your lane (a **signed, principal/tenant-bound lane token**, not a bare header) route to your fork, everything else stays baseline — the **real rest-of-system** serves it, no full clone. The token is **enforced fail-closed at every membrane hop and on the `EventEnvelope.lane` for async** ([ADR-0076](./adr/04-governance-verification.md#adr-0076) R1/R2): a hop or subscriber that can't prove in-lane provenance **denies — never falls through to baseline**. A fork must **satisfy the boundary contract at lane join** (a runtime check, distinct from deploy-time `can-deploy`, [Plan 29](./contracts-policy-flags.md#plan-29)) so it can't break shared consumers; **baseline aggregates fork-on-touch** so a lane write never appends the real stream ([Plan 32](./data-plane.md#plan-32)); **real external side effects default to `mock`/`record` in-lane**; the lane runs under a **resource budget** so a bad fork can't degrade the baseline. The heavier **ephemeral-Camp clone** ([Plan 25](./platform-engineering.md#plan-25)) is the escape hatch for deep stateful isolation.

The same mechanism powers **preview environments** (per-PR lane or ephemeral Camp, [Plan 25](./platform-engineering.md#plan-25)), **AI self-healing experiments** (try a candidate fix on a strictly-isolated `shadow`/`fork` lane against shadowed real traffic, score via evals, promote only through the gated canary — [Plan 23](./forge-generated-stack.md#plan-23)/[Plan 40](./operators-sre.md#plan-40)), and **non-destructive chaos** (`fault` bounded to a lane). **Honesty about what a sandbox proves** ([ADR-0042](./adr/07-portability-extensibility.md#adr-0042)): a `mock` is contract-conformant (*shape*), **not** behaviorally complete, so an all-mock run carries the `mock`/`simulate` fidelity label and **`hobo verify` refuses a prod-ready claim from it** (graded: declared < observed/promoted < replay-of-recorded) — the message is *"passed against mocks, not the real service."* A lane run is **replayable only with its baseline read-through recorded** (value + observed `seq`); the propagation guarantee is the **fail-closed signed token at runtime**, while `@hobo/conformance` only verifies each port adapter forwards the `lane` field.

### Per-plan verification
- **SDK ([2](./sdk-api.md#plan-02))** — `examples/hello-bindle` runs on `runtime-local`: a workflow + actor + saga execute; killing/restarting resumes; **replay reproduces identical state** (determinism test); types compile with provider options. **Codegen test** ([ADR-0037](./adr/05-config-matching-environments.md#adr-0037)): from a fixture bindle, the generated `_generated/` types compile, `ctx.bindings.db` is typed to the resolved client, a typed `useQuery` reflects the query shape, and **`hobo codegen --check` fails on a hand-edited drift**.
- **Providers/IaC ([3](./control-plane.md#plan-04))** — `examples/multi-cloud-shop` deploys the *same* Bindle to two providers via mapping rules; assert provider-specific `.with(...)` options only affect the resolved provider; Planner rejects an unsatisfiable `require` with a precise reason.
- **Control plane/HA ([4](./control-plane.md#plan-04),[5](./reliability-observability-cost.md#plan-05))** — kill the Yard mid-deploy → resumes from the log; inject a provisioning failure past the no-go threshold → saga compensation rolls back in reverse-dependency order; partition an actor owner → fencing rejects its stale writes; canary regression → auto-rollback.
- **Event model ([11](./event-model.md#plan-11))** — rebuild every projection from zero == live projection (proves the log is authoritative); old events replay through upcasters.
- **Agent auth ([6](./ai-native-agent-auth.md#plan-06))** — an agent obtains a short-lived provider token via OIDC federation (no static secrets), provisions a resource, and the `token.*` events exist + the run is replayable; a high-risk action blocks on a policy gate.
- **End-user auth ([36](./ai-native-agent-auth.md#plan-06))** — a JWT from a fixture IdP is verified via JWKS → `ctx.user` carries the claims; an **expired/wrong-issuer/tampered** token is rejected; a **policy/`.allow()` rule keyed on user claims** gates a query/mutation (allow + deny); **revocation** (`session.Revoked`) blocks subsequent requests **and re-pushes affected reactive queries** ([32](./data-plane.md#plan-32)); the **thin built-in dev provider works offline** ([ADR-0036](./adr/07-portability-extensibility.md#adr-0036)).
- **Security ([12](./security-networking.md#plan-12))** — cross-tenant read attempts fail at the Gateway and the store; an Executor has no egress beyond its scoped target; an unsigned plugin is refused by the Registry.
- **Networking ([13](./security-networking.md#plan-12))** — cross-provider services connect over mTLS keyed by SVIDs; the topology graph reports the correct connectivity tier + egress.
- **Cost ([16](./reliability-observability-cost.md#plan-05))** — `hobo plan` estimate is within tolerance of a known fixture; a budget breach blocks or requires approval.
- **MCP/DX ([15](./developer-experience.md#plan-07))** — a real agent drives `plan`→`deploy`→`inspect_run` through `@hobo/mcp`; `hobo dev` runs the agnostic path with zero cloud.
- **WASM/WASI runtime ([20](./wasm-runtime-wit.md#plan-20),[24](./wasm-runtime-wit.md#plan-20))** — a TS service builds to a component via jco; conformance runs **per WIT interface**; swapping a provider behind a port is a link change (no recompile); deny-by-default holds (an un-linked capability call fails).
- **Resources/IfC ([21](./authoring-resources-wiring.md#plan-21),[22](./authoring-resources-wiring.md#plan-21))** — `hobo collect` emits a **manifest** matching a fixture; `.allow()` produces exactly the expected IAM + link + token-scope triple; a missing verb is denied on all three.
- **Stubbable/AI ([23](./forge-generated-stack.md#plan-23))** — run with a `stub()` behind a port, record traces, then assert a Forge-generated implementation **passes conformance and reproduces the recorded traces**; a simulated SLO regression drives a **gated** live-fix that auto-rolls-back on failure.
