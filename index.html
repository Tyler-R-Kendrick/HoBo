Pack your bindle Learn the lingo
src/bindle.ts 
import { bindle } from "@hobo/bindles";

import { app as helloApi } from "./api";
import { app as helloWeb } from "./webapp";

// Pack once — provider-agnostic by construction.
export default bindle("hello-bindle", (b) => {
 const api = b.api(() => helloApi.fetch);
 const web = b.web(() => helloWeb.fetch).dependsOn(api);
 return { api, web };
});
Why HoBo exists

Two bad landlords, and the open road

Modern teams pick between a closed PaaS that owns them and raw IaC that consumes them. HoBo's founding grudge: your code shouldn't pay a loyalty tax to its landlord.

The company town

A closed PaaS is easy right up until the rent triples. One runtime, one bill, and the exits are decorative.

The fixer-upper

Raw cloud + IaC gives you full control — of a second job. Every app team slowly becomes a part-time platform team.

→The HoBo way

Travel light. Describe intent, not infrastructure, and let policy, price, and reliability goals pick the home. Need provider-native power? It's one typed .with(...) away.

The guiding principle

Deployment is not a destination. It's a journey.

Other platforms deploy your app and call it a day. HoBo keeps watching the market: when a cheaper home passes your policy gates, it plans the move, rehearses it, and rides — with your blessing or on full auto.

01 · PACK

Author the Bindle

Everything your app owns, rolled into one provider-agnostic bundle: services, resources, wiring, and inline .allow() least privilege. If it's not in the bindle, it doesn't ship.

02 · SETTLE

Pitch a Camp

A Camp is the environment shape your app occupies (prod, staging, …) and the durable runtime substrate. Pitch one to pin env semantics — or write none and HoBo infers a camp. Provider selection lives on the Yard.

03 · RIDE

Continuous migration

Price drops, credits appear, a region gets flaky — HoBo replans placement continuously and moves the bindle when it's worth it. Same convergence loop as hobo up, so a move is never a special event.

MigrationPlanned Gated Migrated

Every hop is an event in an append-only log — replay the journey, audit every fare, roll back any move. How the moving works →

The vocabulary

Four words for traveling light

HoBo's primitives are named for the life: pack a bindle, pitch a camp, work a yard, meet at the junction — plus stations for control isolation and trails for continuous moves. Start with the bindle.

Bindle start here

The app, packed: services, resources, wiring, policies, and deployment intent — provider-agnostic by construction. The same bindle unpacks anywhere, which is exactly what makes it cheap to move.

Pack your first bindle →

Camp then here

Environment shape and runtime requirements — not the cloud account. Pitch one to pin prod/staging semantics, or skip it and HoBo infers a camp on the local lane.

Pitch a camp (optional) →

Yard advanced

Provider selection point: one provider, zero or more camps, shared policy and identity. Self-hostable — the Yard is itself a bindle.

Run a yard →

Junction advanced

Where yards meet: cross-cloud federation for hybrid and multi-cloud — peer yards, no shared mutable state.

Wire a junction →

Station ops

Hard isolation boundary a Conductor occupies — rails, connections, fail-closed setup. Not app topology.

Init a station →

Trail migrate

App-owned continuous migration recipes: duals, rebinds, cutover — composing identity continuous when you need it.

Plan a trail →

Replayable event log

Every deploy, migration, and token grant is an appended event. Time travel isn't a feature, it's the data model.

WIT/WASM ports

Ports are WIT interfaces; apps are wasm components (with an OCI fallback); providers are capability providers. That thin, typed port contract is what makes moving homes cheap — any Component-Model language rides the same rails.

AI-native

Built for humans, and the agents that work for them

Every capability is reachable via SDK, CLI, and MCP. Agents aren't a chat box bolted on — they're principals with their own scoped, short-lived credentials.

Agents as principals

Agents self-provision exactly the credentials a task needs through a machine-readable capability standard — and every token issued is an auditable event like everything else.

The Crew: a built-in operator workforce

SRE, Endpoint Monitor, GitOps, Platform Engineer, SWE, UX Designer, and FinOps ship as policy-gated Yard operators — HoBo ships the operators, not just the APIs they'd call. Built-in operators →

Greenfield from a declaration

Declare a @component class whose @operation methods carry intent, a typed contract shape, and an optional rubric enforced as policy — then hand it to b.api(...). Stubbed operations run day one, and the generation pipeline grows the real implementations — promoted only past conformance, eval thresholds, and policy. Declare first, generate the code →

AI-generated providers, conformance-certified

Missing an adapter for your favorite discount host? The generation pipeline writes it; the port's contract suite certifies it. More homes on the map, cheaper moves for everyone. Build a custom provider →
