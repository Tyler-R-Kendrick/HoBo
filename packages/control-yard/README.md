# `@hobo/control-yard`

**HIGHBALL!** — the game-first control-plane UI: a top-down pixel-RPG village
rendered from real projections (Phaser 3 host + OpenUI generative overlays).
ADR-0147, art identity per ADR-0148.

The yard is an *observed* world: every prop, character, and signal is a 1:1
rendering of a real projection, and the goal state — the **highball**, a clean
board — is generated by reality alone. The approval gate is the core verb:
mutations arrive as waybills you read and **stamp** or **spike**, firing the
same `@hobo/management` functions as the CLI.

Skills applied from `ref_assets/` builderpack:

| Skill | Use in this package |
|---|---|
| **gamedev-assets** | Measured `assets/assets_index.json` (v2 categories), `asset_sizes` / `asset_sheet_probe` / `asset_manifest_check`, frame extract + review GIFs |
| **phaser-gamedev** | Measure-before-load STOP rule, Boot load plan, AnimTest harness, FIT config, pooling-ready particle design, no global game state |
| **playwright-testing** | `window.__TEST__` seam, `?test=1&seed=42` deterministic mode, readiness waits, `imgdiff.py` baselines |

## How to run

```bash
# 1) Asset pipeline (gamedev-assets)
pnpm --filter @hobo/control-yard run assets:sizes
pnpm --filter @hobo/control-yard run assets:coverage
pnpm --filter @hobo/control-yard run assets:validate
pnpm --filter @hobo/control-yard run assets:extract-frames
# then make GIFs via skill:

# 2) Unit tests
pnpm --filter @hobo/control-yard test

# 3) Evidence capture (AGENTS.md mandatory — screenshots + MP4)
pnpm --filter @hobo/control-yard run evidence
pnpm --filter @hobo/control-yard run evidence:check
# → public/shots/*.png + recordings/*.mp4 + evidence-manifest.json
# Syncs key files into src/draft/exp-proofs/ux/control-yard/assets/evidence/
```

**Self-report is not acceptance.** See `AGENTS.md` for required PNG/MP4 evidence rules.


Playable host: `public/index.html` + `public/dist/yard.js` (esbuild bundle of
`src/main.ts`, the only module that constructs `Phaser.Game` — ADR-0147).
Rebuild it with `pnpm --filter @hobo/control-yard run bundle`; `play`,
`serve`, and `evidence` do so automatically.  
Anim isolation: `public/anim-test.html` (phaser-gamedev AnimTest pattern)

Run it against a live control plane, or against the seeded simulator when you
have no station yet:

```bash
hobo serve control --demo --demo-seed 42   # world read model from the simulator
```

Demo/simulated data always renders behind a **SIMULATED** tag — see the signal
provenance rules in `DESIGN.md`.

## Design system + art

- **`site/DESIGN.md`** (mirrored `DESIGN.md` here) — the pixel-RPG contract:
  16px tile grid, integer scaling only, hard `#3f2631` outlines, square corners,
  earth-and-slate palette. See [ADR-0148](../../docs/design/adr/07-portability-extensibility.md#adr-0148).
- **`assets/kenney/`** — vendored CC0 tilesets (Kenney), each with its upstream
  licence beside it. **Art is sourced, never drawn in renderer code**: assembling
  props from rects and lines is what produced the surface this replaced.
- **`assets/CREDITS.md`** — per-asset provenance; every manifest entry needs a row.
- **`src/village.ts`** — the tile vocabulary: which tile index means what, where
  houses sit, how the road transitions, which villager a given Bindle always gets.

Vendored sheets:

| Id | Sheet | Grid | Use |
|---|---|---|---|
| `town` | `tiny-town/tilemap_packed.png` | 12×11 @16 | ground, houses, fences, props |
| `dungeon` | `tiny-dungeon/tilemap_packed.png` | 12×11 @16 | hazard + interior props |
| `urban` | `rpg-urban/tilemap_packed.png` | 27×18 @16 | modern/industrial props |
| `rogue` | `roguelike-rpg/roguelikeSheet_transparent.png` | 57×31 @16, sp 1 | extended terrain |
| `chars` | `roguelike-characters/roguelikeChar_transparent.png` | 54×12 @16, sp 1 | villagers = Bindles |
| `ui` | `fantasy-ui-borders/panel-000.png` | 3×3 @16 | nine-slice panels |

The world mapping is 1:1 with real projections — Station is the town, a Camp is a
house, a Bindle is the villager outside it, the active rail is the road, a
Connection is the gate, the waybill desk is the notice board, quota and spend are
the treasury, and a clean board raises the banner.

Notes: `docs/asset-index-learnings.md`.

## Architecture (phaser-gamedev)

```
Boot/Preload/Yard scenes  ← thin Phaser adapters (src/phaser/scenes.ts)
Presenter                 ← pure state → RenderModel (headlessly testable)
Yard engine               ← projections only (event-sourced)
World model               ← @hobo/yard-world, fed by OTLP via control-api
UI sheets                 ← OpenUI-style schema stream; waybills stamp/spike
__TEST__ seam             ← ready / state / commands / scenarios
```

The scenes hold no logic: they reconcile the presenter's declarative
`RenderModel` into GameObjects, so what the yard draws is unit-testable
without a browser.

Sprites resolve through vendored sheet ids plus a tile index, and the mapping
from control-plane state to tile lives in `src/village.ts` — never inline in the
renderer.
