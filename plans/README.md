  parsed persona/profile-digest contract.
- 002 needs both contracts so objective vectors use real experiment evidence
  and persona thresholds. 004 likewise needs 001's coverage contract and 003's
  parsed persona model instead of generating renamed copies.
- 005 is last because host adapters must delegate to the final canonical state

## Findings considered and rejected

- Add a new workflow framework or hosted optimization service: rejected. The
  existing TypeScript runner, bus, survey, scorecard, and feature validators are
  sufficient once they enforce semantics.
- Add an LLM call inside deterministic persona/feature generators: rejected.
  Host agents already supply language-model judgment; deterministic code should
  expose grounded inputs and enforce quality, not add keys, cost, or egress.
- Treat one failed uplift as proof of a global mathematical Pareto optimum:
  rejected. The implementable contract is a scoped local equilibrium over the
  enumerated S/M candidate set, and the artifacts must say so honestly.
- Rewrite existing `packages/code/.optimizexp/**` artifacts in these plans:
  rejected. They are concurrent user work and serve only as audit evidence.
