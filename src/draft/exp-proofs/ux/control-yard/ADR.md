# ADR — Control-Plane Yard experience proof

**Status:** Accepted  
**Related:** [ADR-0135](../../../../docs/design/adr/07-portability-extensibility.md#adr-0135), ADR-0131, ADR-0111

## Decision

Prove the Yard game UX as an experience proof: zones map to Station/Rail/Connection
projections; generative sheets confirm via `@hobo/management`; Bo assets obey the
parallax art bible. Production packages: `@hobo/management`, `@hobo/control-api`,
`@hobo/control-yard`.
